隱私權政策

最後更新：2026 年 10 月 29 日

「信用卡帳單下載」是本人自用的工具，唯一的使用者是本人。

存取的資料

本工具透過 Google OAuth 取得 Gmail 唯讀權限（https://www.googleapis.com/auth/gmail.readonly），只用來搜尋並下載本人信箱中銀行寄送的信用卡電子帳單附件。

資料的使用與保存

  • 下載的帳單與整理後的資料只保存在本人的電腦上。
  • 不會將任何 Google 使用者資料傳送、出售或分享給第三方。
  • 不會將資料用於廣告或其他與上述用途無關的目的。

Google API 使用者資料政策

本工具對 Google API 所取得資訊的使用，遵守 Google API 服務使用者資料政策，包括「有限使用」的規定。

撤銷授權

可隨時到 Google 帳戶的第三方存取權頁面 移除本工具的存取權。
